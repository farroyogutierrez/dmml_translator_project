# german <-> english machine translator
project #3 / final project for csc 4422 (data mining and machine learning). german <-> english machine translator.

# requirements:
- google colab

# set up:
- click "Open in Colab" badge on the top left of the preview
- click "Connect" on the top right
- click "Run All" on the top left

# note: there is no save/load state for both models, therefore one must train both models on each run (takes roughly two hours). a new translator is being worked on to include this notable feature to speed up the translation process and to include more language options.
